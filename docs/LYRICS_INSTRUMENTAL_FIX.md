# 网易云纯音乐提示修复

2026-10-13 已查看网易云当前歌曲窗口：歌手雪色、专辑《消失》，歌名为不可见字符，歌曲 ID 3339531841。播放器显示“纯音乐，请欣赏”；[网易云歌词接口](https://music.163.com/api/song/lyric?id=3339531841&lv=1&kv=1&tv=1&yv=1) 的实测响应是 code=200、pureMusic=true、lrc.lyric 为空。

旧实现只接受非空歌词文本，忽略 pureMusic 标志，于是把成功的纯音乐结果当成获取失败，继续来源回退，最后没有任何提示。

现将已确认纯音乐作为 LyricDocument 的 isInstrumental 状态。网易云响应解析、曲长判定、服务发布和缓存均接受该状态，停止继续回退。Direct2D 在歌词区域以普通文本显示“纯音乐，请欣赏”，保持固定，不滚动、不渐进着色；关闭歌词显示时也隐藏提示。普通歌词缺失、空响应及错误响应不会被误标成纯音乐。顺带修复空 YRC 阻止有效 LRC 被使用的问题。

验证包括当前歌曲的真实响应样本、空／错误响应、正常 LRC 回退、服务发布与来源回退停止、缓存保留、清空歌曲，以及实际 GPU 像素中的提示可见、静止、未着色和显示开关联动。八项 CTest 全部通过，构建无新增警告。

修复版已启动于 build-qt-release/MusicBar.exe，产物与测试构建的 SHA256 一致，大小 29,237,248 字节；设置文件切换前后 SHA256 一致，未操作播放器的播放、暂停或切歌。替换前 EXE 备份在 build-qt-design/previous-runtime/MusicBar-before-instrumental.exe。
